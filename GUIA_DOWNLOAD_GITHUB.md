==============================================
📥 COMO BAIXAR O PROJETO DO GITHUB
==============================================

Escolha UMA das 4 opções abaixo:

==============================================
OPÇÃO 1: VIA TERMINAL/CMD (RECOMENDADO)
==============================================

VANTAGENS:
✓ Mais rápido
✓ Recebe atualizações facilmente
✓ Ideal para desenvolvimento

PASSOS:

1. Abra Terminal (Windows) ou CMD
   - Pressione: Win + R
   - Digite: cmd
   - Pressione: Enter

2. Navegue até o local desejado
   $ cd C:\Users\seu-usuario\Documents

3. Clone o repositório
   $ git clone https://github.com/SEU-USUARIO/painel-regulacao-estadual.git

4. Entre na pasta do projeto
   $ cd painel-regulacao-estadual

5. Pronto! Todos os arquivos foram baixados

PARA RECEBER ATUALIZAÇÕES:
   $ git pull origin main

==============================================
OPÇÃO 2: GITHUB DESKTOP (MAIS FÁCIL)
==============================================

VANTAGENS:
✓ Interface gráfica amigável
✓ Não precisa aprender Git
✓ Gerencia repositórios visualmente

PASSOS:

1. Baixe GitHub Desktop
   Acesse: https://desktop.github.com/

2. Instale no seu computador

3. Faça login com sua conta GitHub

4. Vá ao repositório no navegador
   https://github.com/SEU-USUARIO/painel-regulacao-estadual

5. Clique no botão verde: "Code"

6. Selecione: "Open with GitHub Desktop"

7. Escolha a pasta onde quer salvar

8. Clique em: "Clone"

9. Pronto! A pasta será criada automaticamente

PARA RECEBER ATUALIZAÇÕES:
   - Abra GitHub Desktop
   - Clique em "Fetch origin"
   - Clique em "Pull origin"

==============================================
OPÇÃO 3: DOWNLOAD DIRETO (SEM GIT)
==============================================

VANTAGENS:
✓ Não precisa instalar nada
✓ Rápido e simples
✓ Ideal para quem não usa Git

DESVANTAGENS:
✗ Não recebe atualizações automaticamente
✗ Precisa baixar novamente para atualizar

PASSOS:

1. Acesse o repositório no navegador
   https://github.com/SEU-USUARIO/painel-regulacao-estadual

2. Clique no botão verde: "Code"

3. Selecione: "Download ZIP"

4. O arquivo será baixado (painel-regulacao-estadual-main.zip)

5. Clique com botão direito no arquivo

6. Selecione: "Extrair tudo..." (Windows)

7. Escolha a pasta de destino

8. Clique em: "Extrair"

9. Pronto! Todos os arquivos estão disponíveis

PARA ATUALIZAR:
   - Repita todos os passos novamente

==============================================
OPÇÃO 4: VS CODE (INTEGRADO)
==============================================

VANTAGENS:
✓ Integrado ao editor de código
✓ Não precisa sair do VS Code
✓ Ideal se você já usa VS Code

PASSOS:

1. Abra VS Code

2. Pressione: Ctrl + Shift + P
   (ou Cmd + Shift + P no Mac)

3. Digite: Git: Clone

4. Pressione: Enter

5. Cole a URL do repositório:
   https://github.com/SEU-USUARIO/painel-regulacao-estadual.git

6. Pressione: Enter

7. Escolha a pasta onde quer salvar

8. Pressione: Enter

9. Clique em: "Abrir repositório clonado"

10. Pronto! VS Code abre a pasta automaticamente

PARA RECEBER ATUALIZAÇÕES:
   - Abra a aba "Source Control" (ícone de garfo)
   - Clique em "Pull"

==============================================
🧪 TESTE APÓS BAIXAR
==============================================

OPÇÃO A - Abrir direto no navegador:
   1. Navegue até a pasta do projeto
   2. Clique duplo em "index.html"
   3. Abre automaticamente no navegador

OPÇÃO B - Com Python (Terminal):
   1. Abra Terminal/CMD
   2. Digite: cd caminho/para/painel-regulacao-estadual
   3. Digite: python -m http.server 8000
   4. Acesse: http://localhost:8000

OPÇÃO C - Com Live Server (VS Code):
   1. Instale extensão "Live Server"
   2. Clique direito em "index.html"
   3. Selecione "Open with Live Server"
   4. Navegador abre automaticamente

==============================================
❓ DÚVIDAS FREQUENTES
==============================================

P: Preciso instalar Git?
R: Não obrigatoriamente. Use Opção 3 (Download ZIP) se não quiser.

P: Qual é a melhor opção?
R: Opção 1 (Terminal) se você quer receber atualizações facilmente.
   Opção 3 (Download ZIP) se quer algo simples e rápido.

P: Como atualizar o projeto?
R: Se usou Git: $ git pull origin main
   Se baixou ZIP: Baixe novamente

P: Posso clonar em qualquer pasta?
R: Sim! Qualquer pasta do seu computador funciona.

P: Preciso de conta GitHub para baixar?
R: Não para as Opções 3 e 4. Para Opção 2 (GitHub Desktop) sim.

P: Onde está o arquivo principal?
R: É o "index.html". Abra no navegador para usar.
